
# BASIL

This package implements a Bayesian Analysis with gene-Sets Informed Latent space (BASIL).

## Installation

You can install the R package with: 

```
library(devtools)
install_github("federicastolf/BASIL")
```

## Usage

Check out the [vignette](vignettes/vignette.pdf) for an example of the package usage.

## Reference

Mauri, L., Stolf, F., Herring, A. H., Miller, C., and Dunson, D. B.  "Pathway-based Bayesian factor models for gene expression data"
