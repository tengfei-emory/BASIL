
# BASIL

This package implements a Bayesian Analysis with gene-Sets Informed Latent space (BASIL).

## Installation

You can install the R package with: 

```
library(devtools)
install_github("federicastolf/BASIL")
```

## Usage

Check out the [vignette](https://raw.githack.com/federicastolf/BASIL/master/doc/vignette.html) for an example of the package usage.
