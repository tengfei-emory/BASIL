
# BASIL

This package implements a Bayesian Analysis with gene-Sets Informed Latent space (BASIL).

## Installation

You can install the R package with: 

```
library(devtools)
install_github("federicastolf/BASIL")
```

## Usage

Check out the [vignette](doc/vignette.pdf) for an example of the package usage.

## Reference

Mauri, L., F. Stolf, A. H. Herring, C. Miller, and D.B. Dunson "Pathway-based Bayesian factor models for gene expression data"
